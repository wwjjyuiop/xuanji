## 要做的事（按顺序，做完一项就在 PROGRESS.md 记一行）

### 第 1 步：补全骨骼别名表（这是"腿能动"的前提）

把 `_BONE_ALIASES` 扩成完整表，至少包含这些键（每个键给出 MMD 名与英文名两种候选，用现有的 `_findBoneWithAlias` 查找）：

```
head, neck, spine(上半身), chest, hips(下半身), center(センター), groove(グルーブ), root(全ての親),
shoulderL/R(左肩/右肩), upperArmL/R(左腕/右腕), elbowL/R(左ひじ/右ひじ), wristL/R(左手首/右手首), handL/R(左手先/右手先),
thighL/R(左足/右足), kneeL/R(左ひざ/右ひざ), ankleL/R(左足首/右足首), toeL/R(左つま先/右つま先),
eyeL/R(左目/右目), eyes(両目), bustL/R(左胸/右胸)
```

再写一个 `_bone(key)` 便捷取骨骼的函数（内部走 `_findBoneWithAlias`），供动作库调用。

### 第 2 步：程序化走路 + 待机自由漫游（验收项 A）

- 写 `walkCycle(t, speed)`：**左右大腿反相摆动**（`左足.rotation.x = A*sin(w t)`，`右足.rotation.x = A*sin(w t + π)`，A 至少 0.25 rad），膝盖跟随（`ひざ` 在下摆相位弯曲）、双臂反向摆动、躯干轻微上下起伏。
- 写漫游状态机：随机挑目标点 → 转身朝目标（平滑插值）→ **沿路径位移**（改 `mesh.position` 或根骨骼 `センター`）→ 到达后停顿随机时长 → 再挑新目标。
- 边界：限制在场景可站范围内，不许走出圆盘/穿模。
- 30 秒内应能看到 **≥2 段走动 + ≥2 次转向**，且有随机性（不是同一循环）。

### 第 3 步：指令动作（验收项 E，腿必须参与）

实现这些动作名（保持与现有 `playAction(name)` 兼容，也支持通过 `setAttention` 切换）：

- `walk`：走路（腿摆动）
- `sit`：坐下 —— **膝盖弯曲 > 0.5 rad**、髋部前屈、重心下沉（`センター` 世界高度下降），并**保持坐姿**直到 `stand`/`stop`
- `stand`：从坐姿站起来（有过程，不是瞬切）
- `wave`：打招呼/挥手（肩+肘+手腕周期性摆动，幅度 > 0.3 rad）
- `bow`：鞠躬（上半身前屈 > 0.4 rad，头随之低）
- `dance`：跳舞（手臂 + 躯干 + **腿按节拍摆动**）
- `stop`：立刻回到站立待机（走 `stopAction()` 的复位路径）
- `nod` / `shake`：点头 / 摇头（小动作，供对话用）

**每个动作都必须可随时被 `stop` 打断**，打断后全身骨骼回到初始姿态（与初始值误差 < 0.01 rad），不残留、不卡半路。

### 第 4 步：注意力状态（验收项 B/C/D）

暴露 `setAttention(mode)`，mode ∈ `wander` / `approach` / `listen` / `speak`：

- `wander`：自由漫游（第 2 步）
- `approach`：**走向相机**并停在镜头前设定距离（比 wander 时明显更近），结束时朝相机（朝向误差 < 15°），到位有自然的减速站定
- `listen`：停在镜头前，头/眼朝向相机，身体微前倾或歪头，**周期性小幅点头**（不能僵住）
- `speak`：停在镜头前，口型随驱动值张合（复用现有元音口型机制，提供 `setSpeakingLevel(v)` 之类的入口），上身与头部有非零的周期性微动

### 第 5 步：语法与健壮性

- `node --check` 对抽出的 JS 做语法检查（可用 `sed`/`awk` 把 `<script type="module">` 内容抽到临时 `.mjs` 再 check，**不要启动浏览器**）。
- 模型未就绪时调用任何新接口都不许抛异常。
- 不要引入每帧 O(n²) 的操作（禁止在骨骼循环里对每根骨骼调用 `updateMatrixWorld(true)`）。
